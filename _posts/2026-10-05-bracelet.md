For this project we created a wrist band that connected to itself using metal snaps. I then attached a battery, green LED, and a button made from felt and satin stitching with conductive thread. The thread was then secured to the metal snaps so that when closed these  snaps created a loop that completed a circuit as long as the button was down. My tip for anyone attempting the same project would be to visualize the circuits you are creating as 3-dimensional to help find redundancies can be cut. Another tip would be to remember that you can always add more material to help insulate or keep parts away from each other. For my rendition this was helpful when I created a third layer of felt to keep my homemade button from making contact when there was no force being placed upon it.
